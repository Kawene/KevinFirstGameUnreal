# First Game Unreal

As the title says. This is my first ever "game" in Unreal Engine. I put in a lot of work, learned so much, but still have a lot to learn. It was made in blueprints because I felt like it was the right thing to start focusing on, and then I would explore the rest when I would be more comfortable with the engine. 

The game is a first-person combat game. You are in a dungeon and your goal is to survive and kill the enemies, but most importantly, you need to go get the magic statuette. 

I am relatively happy with the result, but it could be a lot better. I made the repository public so that my efforts and learning proof are online somewhere. In a few years, I could go back and see where I started from and be proud of the developer I have become.

I stopped working on this project because I wanted to focus my learning on the c++ side of Unreal and I thought creating a new project would be the best way to learn it without breaking anything.
